## FAQ
### MCP는 무엇인가?
MCP (Model Context Protocol)는 AI 애플리케이션이 외부 데이터 소스와 도구에 안전하게 연결할 수 있는 공개 프로토콜입니다.
### MCP를 시작하는 방법은 무엇인가?
MCP 서버 컬렉션을 탐색하여 시작하고 설치 가이드를 따르세요.
### MCP는 프로덕션 사용에 안전한가?
인증 및 보안 모범 사례와 함께 올바르게 구성된 경우 MCP 서버는 프로덕션 환경에 적합합니다.
