# テンプレートを超えて: canvas-design で美術館品質のアートをつくる

Canva のような汎用テンプレートであふれる世界では、本当に印象に残るデザインは **意図** によって際立ちます。プロのデザインは、ロゴをどこに置くかだけではありません。形、余白、色の哲学が、あらゆるピクセルを導くことです。

Anthropic 公式の **canvas-design** スキルは、AI エージェントを単なるレイアウト生成から、高品質なビジュアルアートの領域へ押し上げます。ブルータリスト風のイベントポスター、ミニマルなブランドアイデンティティ、洗練された PDF レポートなど、どのような制作でも職人的で専門的な仕上がりを実現します。

```bash
# canvas-design スキルを追加
npx killer-skills add anthropics/skills/canvas-design
```

## canvas-design が特別な理由

多くの AI ツールは「見た目がよさそうなもの」を推測します。一方で `canvas-design` は **Manifesto-First** の考え方で動きます。あらゆるデザイン依頼を、新しい美学的ムーブメントとして扱うのです。

### 1. ビジュアル哲学を先につくる
一つの図形を描く前に、エージェントは **ビジュアル哲学** を組み立てます。これは単なるチェックリストではなく、そのムーブメントの魂を掘り下げるプロセスです。たとえば次のような方向性があります。

- **「Brutalist Joy」**: モニュメンタルな形と生々しい率直さ
- **「Chromatic Silence」**: 色を主な情報伝達手段にし、テキストを最小限に抑える
- **「Analog Meditation」**: 粒子感、にじみ、広大な余白を積極的に取り入れる

### 2. 空間によるコミュニケーション
このスキルはテキストよりも **空間的コミュニケーション** を重視します。基本は 90/10 ルールです。90% をビジュアルデザイン、10% を必要最小限のテキストに充てます。文字は情報ブロックではなく、作品の構造に統合された強い視覚アクセントとして扱われます。

## 重要なデザイン原則

`canvas-design` は、美術館レベルの完成度を支えるいくつかの譲れない基準を持っています。

### 要素の重なりゼロと完璧なマージン
プロ品質とは、要素がページからはみ出さず、意図せず重ならないことです。すべての要素に十分な「呼吸する余白」を与え、クリーンで洗練された印象をつくります。

### 熟練したタイポグラフィ
このスキルは高品質なフォントを使い、文字組みそのものを作品の一部として扱います。アマチュア的な文字配置を避け、テキストを幾何学的な造形として統合します。

### 手仕事のような完成度
目指すのは、**何時間も手で磨き上げたように見える** 作品です。構図は瞑想のような丁寧さで整えられ、長く見続けるほど魅力が深まります。

## 実践的なユースケース

### ブティックイベントのポスター
コレクションしたくなるようなポスターを作れます。「Concrete Poetry」のようなムーブメントを使えば、大胆な色面と彫刻的なタイポグラフィで一瞬で視線をつかめます。

### ミニマルなブランドアイデンティティ
抑制と秩序を重視するブランドのためのビジュアル言語を構築できます。「Geometric Silence」は、グリッドベースの精密さと大胆な余白で、高級感のある印象を生み出します。

### アート作品としてのビジュアル
はかなく見えるものでも、研究し、地図のように整理できることを示す作品も作れます。こうした「架空の学問」の図版では、密な痕跡の蓄積と重層的なパターンが、深く意味のあるアートを生み出します。
