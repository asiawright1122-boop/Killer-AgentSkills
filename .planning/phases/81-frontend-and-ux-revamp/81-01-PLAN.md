# Plan for Phase 81: Frontend & UX Revamp

## Objective
Fulfill UX-10 and UX-11 by exposing search globally in the Header and improving the reading experience on Skill Detail pages.

## Steps

### Step 1: Global Search Visibility (UX-10)
1. Modify `src/components/Header.astro` (and relevant locale versions) to include a prominent Search button.
2. Ensure the Search button displays the `Cmd+K` hint.
3. Wire the Search button to toggle the `CommandBar.tsx` state (this may require a lightweight global store like nano-stores, or dispatching a custom event that `CommandBar` listens to).

### Step 2: Skill Details Typography & Markdown (UX-11)
1. Review `src/islands/SkillReadme.tsx` and `src/pages/[locale]/skills/[owner]/[...repo].astro`.
2. Introduce `@tailwindcss/typography` (if not already present and configured) to properly style the rendered markdown (the `prose` class).
3. Ensure code blocks have syntax highlighting. If `rehype-pretty-code` or similar isn't configured, add a lightweight CSS-based solution for code block contrast and styling.
4. Improve layout padding to ensure a comfortable line length (`max-w-prose` or `max-w-3xl`) for documentation.

### Step 3: Verification
1. Run local dev server.
2. Verify search toggle works.
3. Verify markdown readability and mobile responsiveness.
