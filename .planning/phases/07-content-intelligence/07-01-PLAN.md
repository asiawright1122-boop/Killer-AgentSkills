# Phase 7: AI Data Harvesting / Subagent Script

<objective>
Build an automated Node.js intelligence script (`scripts/ai-enrich-thin-skills.ts`) that scans the internal GitHub skills catalog for "thin content" (short README files) and feeds them into SiliconFlow/Nvidia LLMs to auto-generate deep, expert-level technical breakdowns and SEO-friendly documentation.
</objective>

<task>
<read_first>
- src/data/skills-cache.json
- scripts/lib/ai.ts
</read_first>
<action>
Create a new script that iterates over `skills-cache.json`.
For any skill where the `body.length < 500` characters, pass its metadata (name, description, tags, sparse body) to the AI endpoint requesting a "comprehensive Markdown technical evaluation" covering:
1. Architecture Overview
2. Setup and Usage
3. Real-world Prompting Use Cases

Then write the expanded chunk back into the JSON cache and log the token throughput statistics.
</action>
<acceptance_criteria>
- The Node.js script is fully defined and directly executable via `npx tsx scripts/ai-enrich-thin-skills.ts`.
- It properly ignores properly fleshed-out articles and targets specifically empty or 'thin' stubs.
- The AI loop accurately updates the `.planning/STATE.md` or raw payload with expanded strings safely without breaking JSON syntax.
</acceptance_criteria>
</task>

<verification>
<must_haves>
- The script MUST utilize `scripts/lib/ai.ts` effectively without leaking API keys.
</must_haves>
</verification>
