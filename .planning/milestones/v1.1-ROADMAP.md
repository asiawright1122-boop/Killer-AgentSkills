# Milestone v1.1: Observability and Governance Hardening

**Status:** SHIPPED 2026-04-06

## Overview

This milestone hardened the operating model behind Killer-Skills so unattended AI enrichment and public-surface governance can be trusted again. The shipped outcome is a cleaner operator lane across provider health, fallback control, planning traceability, and locale/content drift detection, without widening cost exposure or weakening the existing SEO and publish safeguards.

## Milestone Summary

### Key Accomplishments

1. Turned provider health into a canonical operator-visible report and gating contract across unattended flows.
2. Locked Workers AI to the free-only envelope while making non-NVIDIA fallback activation explicit and auditable.
3. Made requirement coverage machine-readable so milestone audits no longer depend on reconstructing completion from prose.
4. Consolidated locale, metadata, breadcrumb, tutorial-shell, and collection drift checks into one governance lane.
5. Closed the milestone with `10/10` requirements satisfied and a passed milestone audit.

### Key Decisions

- Keep NVIDIA as the preferred healthy path and treat `siliconflow`, `openrouter`, and `cloudflare` as explicit backups rather than silent rotation members.
- Keep Workers AI strictly `free-only`; cost posture is part of the product contract, not just an implementation detail.
- Treat only roadmap-listed phases in the current milestone as active discovery targets and archive orphan planning inputs outside `.planning/phases/`.
- Make route/content contract drift blocking by default while keeping collection drift and locale gaps warning-oriented unless thresholds are crossed.

### Issues Resolved

- Provider-health signaling lived in fragmented reports and YAML snippets instead of one operator contract.
- Backup providers could become active without enough runtime evidence or explicit policy intent.
- Milestone audits still depended on manual reconstruction from planning prose.
- Locale/content drift risk was spread across separate checks instead of one severity-aware governance lane.

### Deferred / Watchlist

- Historical NVIDIA volatility remains visible in trailing windows even though the latest provider-health snapshot is healthy.
- `src/pages/api/skills/try.ts` now mirrors the fallback-policy contract, but it still runs in a different runtime shape than the Node-side `AIService`.
- The new locale/content governance lane is operator-ready, but it is not yet wired into CI or scheduled monitoring.
- Live production smoke and broader crawl-health remain adjacent signals rather than direct subchecks inside the governance report.
