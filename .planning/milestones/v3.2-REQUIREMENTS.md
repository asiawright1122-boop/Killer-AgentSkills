# Requirements: v3.2 CI/CD Typecheck Alignment & Tech Debt Remediation

## Overview

Establish project-wide type safety and resolve compiler-level configuration deprecations. This milestone focuses on cleaning up typescript warnings/errors in the `workers` and `packages/cli` workspaces, setting up typechecking constraints for the core operational scripts under the `scripts/` directory, and integrating these checks into a unified CI gate.

## v3.2 Requirements

- [x] **AIOPS-15**: Resolve typescript compiler deprecation warnings and errors (such as TS5101, TS5107) in `workers/tsconfig.json` and `packages/cli/tsconfig.json`.
- [x] **AIOPS-16**: Create a dedicated `tsconfig` configuration for the `scripts/` directory and remediate all type safety violations, missing parameter declarations, and mismatched interfaces across scripts and test files.
- [x] **AIOPS-17**: Add a unified typecheck validator to CI/CD workflows and verify all packages pass type safety checks automatically before shipping.

## Scope

### 1. TS Compiler Modernization (Phase 94)
- **Problem**: Legacy TS configuration keys like `baseUrl` and older `moduleResolution` policies raise deprecation warnings (TS5101/TS5107) on modern typescript versions, threatening future compiler compatibility.
- **Requirement**:
  - Update `workers/tsconfig.json` to eliminate `TS5101` (by removing `baseUrl` or setting `"ignoreDeprecations": "5.0"` / `"6.0"`).
  - Update `packages/cli/tsconfig.json` to migrate from `"moduleResolution": "node"` to `"bundler"` or a compliant alternative to eliminate `TS5107`.
  - Validate that `npx tsc --noEmit` compiles cleanly in both sub-packages without deprecation logs.
- **Verification**: Running compilation scripts on sub-projects outputs 0 errors and 0 warnings.

### 2. Operational Scripts Type Safety (Phase 95)
- **Problem**: The `scripts/` folder, containing critical data harvesting, caching, translation, and SEO pipelines, is excluded from typescript typechecking, leading to silent type regressions.
- **Requirement**:
  - Introduce a dedicated `scripts/tsconfig.json` defining strict rules for the scripts directory.
  - Resolve all compilation failures within `scripts/`, including implicit `any` parameter typing, undefined object properties, and interface mismatches in execution queues/test suites.
  - Fix type-mismatches in `scripts/lib/recovery-execution-queue.test.ts`, `scripts/lib/recovery-experiment-ladder.ts`, and other modules.
- **Verification**: Running `npx tsc --noEmit --project scripts/tsconfig.json` completes successfully with 0 errors.

### 3. Unified CI/CD Gates (Phase 96)
- **Problem**: Lacking a project-wide type safety validation step in CI allows buggy commits or mismatched signatures to be merged.
- **Requirement**:
  - Combine typechecking for root, `workers`, `packages/cli`, and `scripts` into a unified verification gate (e.g., `npm run typecheck` or equivalent CI workflow integration).
  - Ensure all packages and operational scripts compile cleanly under a single check.
- **Verification**: Single trigger validation runs typechecks on all workspaces and returns exit code 0.
