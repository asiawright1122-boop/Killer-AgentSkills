# Requirements: v3.0 Advanced Search Engine Optimization

## Overview

Maximize organic search traffic, click-through-rates (CTR), and crawl speed by introducing rich structured schema markup, dynamic crawler internal links, and instant submission of modified sitemaps/URLs via IndexNow.

## Scope

### 1. Dynamic JSON-LD Schema (Phase 88)
- **Problem**: Skill and workflow listings appear generic in search engine snippets, resulting in lower CTR.
- **Requirement**: Inject structured JSON-LD schemas inside the HTML headers of skill details and category routes:
  - [x] Skill detail pages must render `SoftwareApplication` and `Product` schemas containing name, owner, stars, forks, quality score, category, and canonical URL.
  - [x] Inject `BreadcrumbList` schema representing the navigational hierarchy.
  - [x] Implement validation guards in build scripts to prevent invalid schema structure from rendering.
- **Verification**: Built HTML output validation successfully returns valid schema parsing using rich results tests rules.

### 2. IndexNow Automated Ingest (Phase 89)
- **Problem**: Crawlers can take days or weeks to index updated directory contents.
- **Requirement**: Create `scripts/submit-indexnow.ts` that:
  - [x] Collects all modified or newly ingested skill URLs during sitemap rebuilds.
  - [x] Dynamically signs the submission payload using an IndexNow verification key.
  - [x] Submits URLs directly to the IndexNow endpoints (Bing, Yandex, etc.).
- **Verification**: Mock executions output properly signed and structured JSON payload matching IndexNow specifications.

### 3. Crawler Semantic Navigation (Phase 90)
- **Problem**: Search engines favor deep semantic link architecture; orphan or shallow pages receive low crawling frequency.
- **Requirement**: Construct an internal linking suggestion component:
  - [x] Detail pages must automatically render 3 to 5 related skills in the same category or sharing topic tags.
  - [x] Link generation must run entirely at build time during Edge pre-rendering to avoid database queries during production runtime.
- **Verification**: Breadcrumbs and related links render on all detail surfaces under Astro build outputs.
