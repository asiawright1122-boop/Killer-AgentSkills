# Phase 71 Plan 71-01: Evaluate Live Traffic Outcome and Unlock Automation Gate

## Goal

Verify returning organic clicks to unlock automated experiment and broad directory expansion gates.

## Depends On

- Phase 70 (selective-authority-expansion-and-backlinks) — code-side complete, manual backlink outreach pending
- Fresh GSC Coverage Drilldown export (post-May 2026)
- At least 3 external backlinks published (GitHub README, dev.to, social)

## Success Criteria

1. The 2026-06 proof window reports >0 daily organic clicks and rising impressions in GSC
2. The automation gate and experiment ladder are unlocked from outcome proof

## Steps

### Step 1: Verify Backlink Impact (manual)

- [ ] Confirm GitHub README badge is live and clickable

- [ ] Confirm social share generated valid OG card impressions
- [ ] Check GSC referral data for backlink-sourced clicks

### Step 2: Ingest Fresh GSC Data (manual + code)

- [ ] Download latest Coverage Drilldown from GSC UI
- [ ] Place in `data/gsc-coverage/` directory

### Step 3: Evaluate Proof Window (code)

- [ ] Run comparable proof window regeneration
- [ ] Check trust verdict upgrade from `warning` to `pass`
- [ ] Verify at least 1 authority surface clears promote gates

### Step 4: Unlock Automation Gate (code)

- [ ] If proof window passes: update `discoveryExpansion` from `closed` to `limited`
- [ ] Enable experiment ladder for automation-candidate classification
- [ ] Update ROADMAP.md Phase 71 status to complete

## Prerequisites Not Yet Met

- [ ] 3+ external backlinks published

- [ ] Organic click data available in GSC

## Risk

If organic clicks remain at 0 after backlink publishing, the proof window will not upgrade and automation stays locked. In that case, Phase 71 becomes a waiting period with periodic GSC rechecks.
