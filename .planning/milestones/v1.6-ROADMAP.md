## Overview

This milestone turned the post-governance recovery effort into an explicit proof-and-gating system. The shipped result preserved dated recovery windows, compared the `v1.5` baseline against fresh cohorts, turned authority-surface expansion into a measurable scorecard, and formalized an experiment ladder that keeps automation locked until manual wins are actually repeatable.

## Milestone Summary

### Key Accomplishments

1. Turned post-governance recovery evidence into dated proof windows instead of latest-state-only artifacts.
2. Added truthful cohort attribution that shows which surfaces are blocked, noisy, flat, `hold`, or `avoid`.
3. Converted authority-surface expansion from intuition into a measurable gate system with explicit `promote / hold / stop` outcomes.
4. Formalized a guarded recovery experiment ladder that keeps automation locked until manual wins prove repeatable.
5. Closed the milestone with `6/6` requirements satisfied, `4/4` phases complete, clean lifecycle hygiene, and a passed milestone audit.

### Key Decisions

- Keep recovery proof truthful even when the result is still `blocking`.
- Prefer explicit expansion gates over volume-biased editorial growth.
- Keep the full skills directory supporting-only instead of restoring it as the lead recovery bet.
- Keep automation behind manual proof and preserve Workers AI `free-only` guardrails during any future rollout.

### Issues Resolved

- Recovery reporting no longer depends on memory or scattered `latest-*` files to interpret post-governance movement.
- Cohort attribution no longer hides blocked cluster truth behind global summaries.
- Discovery expansion no longer reopens just because authority surfaces exist; they now need to earn promotion.
- Recovery experiments no longer jump from idea to automation without one shared promotion and rollback contract.

### Deferred / Watchlist

- The current proof substrate is still the first seeded comparable window, so `trustVerdict=blocking` remains correct.
- The freshest local Coverage Drilldown raw export is still dated `2026-04-03`, leaving cluster truth partially blocked.
- No authority surface is currently promote-ready, so discovery expansion remains correctly closed.
- No experiment is currently automation-ready, so automation remains correctly locked.
